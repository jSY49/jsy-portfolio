## 프로젝트 개요

공연장에서 사용되는 BLE 기반 응원봉 연동 안드로이드 앱을 양산 개발 및 운영.
- **기간** : 2023.10 - 2026.05
- **팀 구성**: 개발 2인 (Android 1인 / iOS 1인) · PM 1인 · 디자이너 1인

## 담당 역할

- BLE 기반 응원봉 연동 안드로이드 앱 양산 개발 및 운영
- 신규 프로젝트 앱 개발 및 출시 (총 17개 앱)
- 운영 중인 상용 앱 48개 유지보수 및 안정화
- Rxjava와 Retrofit을 사용하여 REST API 통신 구현 및 서버 연동 코드 리팩토링
- 현장 사용 환경(공연장 내·외부)을 고려한 예외 처리 및 오류 대응
- 구글 플레이 스토어 배포 및 운영 이슈 대응
- QA 시나리오 작성, 테스트 및 릴리즈 전·후 품질 관리 수행
- Java 기반 레거시 코드 리팩토링을 통해 구조 개선 및 유지보수성 향상
- 공장 및 외주 개발자 검수용 응원봉 OTA 솔루션 개발
- 신규 서비스 도입 검토를 위한 프로토타입 개발 (ML Kit 기반 OCR)

## 성과

- 실제 공연 현장에서 사용되는 응원봉 연동 앱 양산
- 국내외 현장 테스트를 통한 BLE 연결 안정성 확보
- 운영 중 BLE 관련 이슈 감소 및 장애 대응 효율 향상
- 레거시 코드 리팩토링을 통해 유지보수성 및 코드 일관성 개선

## 사용 기술

`Java` `XML` `Kotlin` `RxJava` `Retrofit2` `BLE` `ML Kit`

## 회고

여러 앱을 동시에 양산·운영하면서, 기능을 하나 추가하는 것 보다 이미 운영 중인 서비스를 안정적으로 유지하며 확장하는 것이 훨씬 더 많은 것을 고려해야 하는 작업이라는 것을 배웠습니다.
특히 일회성으로 사람들이 많이 모인 공연장에서 사용자가 주로 사용하게 되는 특성상 실내에서는 드러나지 않던 문제들을 현장에서 직접 마주하며 예외 처리의 중요성을 체감했습니다.
