## 프로젝트 개요

대량의 응원봉 데이터 수신 검증을 위해, 시리얼 통신으로
안테나 제어 하드웨어 장비에 패킷을 전송하고 동작을 지시하는 테스트 도구를 개발했습니다.

- **기간** : 2026.01 - 2026.02
- **팀 구성** : 1인 

## 담당 역할

- 기존 C++ 기반으로 개발되어 유지보수가 어려웠던 프로그램을 C#/WPF로 재개발
- 노트북 ↔ 안테나 제어 장비 간 시리얼 통신 로직 구현
- 테스터(QA 인력)의 사용 편의를 고려한 UI 설계 및 개선

## 성과

- BLE 연동 앱과 연계한 하드웨어 데이터 송수신 검증 환경 구축

## 사용 기술

`C#` `WPF` `Serial Communication`

## 회고

기존 유지보수가 불가능한 C++ 코드를 C#으로 재개발하면서, "동작하는 코드"를 그대로 옮기는 것과
"유지보수 가능한 구조로 다시 설계하는 것"은 전혀 다른 작업이라는 걸 체감했습니다.
특히 시리얼 통신처럼 하드웨어와 직접 맞닿는 로직은 예외 상황(연결 끊김, 응답 지연 등)을
얼마나 촘촘하게 가정하고 설계하느냐가 실제 현장에서의 안정성을 좌우한다는 것을 배웠습니다.
